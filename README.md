# Armoury: Orks

Armoury: Orks is a planned armoury mod for *Warhammer 40,000: Rogue Trader* that aims to add a selection of Ork weapons for player use.

## Status

**Prototype development**

The final weapon selection is not fixed yet. Weapons may be removed or added depending on animation compatibility, available models, balance, and implementation effort.

## Current prototype

Version **0.0.4** contains the first in-game Choppa prototype:

- custom optimized FBX model and textures;
- one-handed axe handling with the `BrutalOneHanded` animation style;
- normal attack and cleave support inherited from the axe setup;
- available for testing through ToyBox under the name **Choppa**.

The current item values and progression are provisional. A tier/level progression inspired by *Armoury: Adeptus Custodes* is planned for a later revision.

## Development

The repository contains the mod-specific source assets and generator code. The local Owlcat Rogue Trader mod template, extracted vanilla blueprints, Unity caches, generated prefabs/materials, and build output are intentionally excluded.
