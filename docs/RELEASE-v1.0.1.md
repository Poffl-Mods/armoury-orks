# Armoury: Orks! WAAAAAGH! — v1.0.1

The Power Klaw now counts as a Power weapon, allowing Power Weapon Specialization to grant its +10 armour penetration. Applies to all six tiers and DA BIG SQUEEZE!.

Power classification confirmed in-game on macOS. This update changes weapon blueprints only; platform-specific assets and runtime files are carried forward from 1.0.0.

## Downloads and installation

- **macOS:** Install `ArmouryOrks-1.0.1-macOS.zip` with Mac ModInstaller.
- **Windows:** Install `ArmouryOrks-1.0.1-Windows.zip` with Modfinder.
- **Checksums:** `SHA256SUMS.txt`.

Requires [MicroPatches](https://github.com/microsoftenator2022/MicroPatches/releases). Update the existing installation and restart the game.
